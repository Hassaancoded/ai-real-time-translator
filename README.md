# 🌐 AI Real-Time Translator (Urdu, Sindhi, Punjabi, Pashto, Balochi)

A real-time AI translator built with Python and Tkinter that translates English text into local Pakistani languages including:

- Urdu 🟢  
- Sindhi 🟡  
- Punjabi (Shahmukhi script) 🔵  
- Pashto 🟠  
- Balochi 🔴

This tool translates text live as you type using Google Translate, optimized for Urdu script rendering and smoother performance.

---

## 🔧 Features

- 📝 Real-time translation as you type
- 🌍 Language selection from a dropdown menu
- ✅ Punjabi shown in **Shahmukhi (Urdu)** script instead of Hindi's Gurmukhi
- 🚀 Optimized for faster performance with threading

---

## 📦 Requirements

- Python 3.6+
- `googletrans==4.0.0-rc1`
- `tkinter` (already comes with Python)

---

## 📥 Installation

```bash
# Clone this repository
git clone https://github.com/your-username/ai-real-time-translator-urdu-sindhi-punjabi.git
cd ai-real-time-translator-urdu-sindhi-punjabi

# Install required library
pip install googletrans==4.0.0-rc1
